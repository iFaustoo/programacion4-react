# Práctica 5 — Sesión global y rutas

Acumula las prácticas anteriores e incorpora `AuthContext`, login por rutas, navegación
protegida y un marco común de aplicación.

Configurá `VITE_API_URL` copiando `.env.example` a `.env.development`, ejecutá
`npm install` y `npm run dev`, y abrí `http://localhost:5174`.
