# Práctica 6 — Búsqueda y paginación

Acumula la sesión global y agrega listado con estados de carga/error, búsqueda por nombre,
filtro de mayores y paginación. Se consulta un registro adicional para identificar si existe
otra página sin mostrar una página vacía al final.

Configurá `VITE_API_URL` copiando `.env.example` a `.env.development`, ejecutá
`npm install` y `npm run dev`, y abrí `http://localhost:5174`.
