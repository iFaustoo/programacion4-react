# Práctica 2 — Lectura de usuarios

Acumula el login e incorpora `GET /user`, `GET /user/me/id` y `GET /user/{id}` para
mostrar la lista y los datos del usuario autenticado.

Configurá `VITE_API_URL` copiando `.env.example` a `.env.development`, ejecutá
`npm install` y `npm run dev`, y abrí `http://localhost:5174`.
