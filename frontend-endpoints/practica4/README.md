# Práctica 4 — Cliente API

Acumula login, lectura de usuarios y sesión persistente. Centraliza `fetch`, headers,
errores HTTP y funciones tipadas por endpoint en `src/api/`.

Configurá `VITE_API_URL` copiando `.env.example` a `.env.development`, ejecutá
`npm install` y `npm run dev`, y abrí `http://localhost:5174`.
