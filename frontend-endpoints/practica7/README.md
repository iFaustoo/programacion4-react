# Práctica 7 — ABM de usuarios

Acumula búsqueda y listado y agrega detalle, alta, edición y baja confirmada de usuarios.
Los formularios convierten y validan los valores antes de llamar a la API.

Configurá `VITE_API_URL` copiando `.env.example` a `.env.development`, ejecutá
`npm install` y `npm run dev`, y abrí `http://localhost:5174`.
