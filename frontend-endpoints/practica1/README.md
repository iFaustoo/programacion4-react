# Práctica 1 — Login

Formulario de login controlado, `POST /login` y presentación del resultado o error.
Es el primer paso del proyecto y todavía no guarda la sesión.

Configurá `VITE_API_URL` copiando `.env.example` a `.env.development`, ejecutá
`npm install` y `npm run dev`, y abrí `http://localhost:5174`.
