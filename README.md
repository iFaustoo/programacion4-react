# programacion4-react

Repositorio de los trabajos prácticos de React de Programación IV.

## Estructura

- [`ejercicios-basicos/`](./ejercicios-basicos/): proyecto Vite con TypeScript
  para los siete ejercicios de «React desde cero».
- `frontend-endpoints/`: se completará con las ocho prácticas cuando se
  incorporen sus consignas.

Para ejecutar los ejercicios básicos, seguí las instrucciones de
[`ejercicios-basicos/README.md`](./ejercicios-basicos/README.md).
