# programacion4-react

Repositorio de los trabajos prácticos de React de Programación IV.

## Estructura

- [`ejercicios-basicos/`](./ejercicios-basicos/): proyecto Vite + TypeScript con
  los siete ejercicios de «React desde cero».
- [`frontend-endpoints/`](./frontend-endpoints/): ocho proyectos Vite + React +
  TypeScript acumulativos, uno por práctica. La práctica 9 se responde en el
  cuestionario y no tiene carpeta.

Las instrucciones para cada proyecto están en su propio `README.md`. No se
versionan dependencias instaladas ni archivos `.env`.
