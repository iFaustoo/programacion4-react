# Ejercicios básicos de React

Proyecto Vite con React y TypeScript que reúne los siete ejercicios de la guía
«React desde cero». Cada consigna tiene su componente en `src/Ej1.tsx` a
`src/Ej7.tsx`, y `src/App.tsx` los muestra con un título identificador.

## Requisitos

- Node.js 20.19+ o 22.12+
- npm

## Desarrollo

```bash
npm install
npm run dev
```

## Verificación

```bash
npm run build
npm run lint
```
